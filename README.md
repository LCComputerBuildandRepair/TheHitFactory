# The Hit Factory — website redesign (mockup)

Multi-page redesign of [thehitfactorylex.com](https://www.thehitfactorylex.com/) for **The Hit Factory**, an indoor baseball and softball training facility at 124 Plymouth St, Unit A, Lexington, Ohio 44904.

Plain HTML + CSS, no build step. Deploy the folder as-is to Netlify or GitHub Pages.

## Pages

| File | Page |
|---|---|
| `index.html` | Home: services, coaching, Elite teaser, sponsors |
| `rentals.html` | Cage rentals ($25 / 30 min, $40 / 60 min) and team rentals ($125 / 1.5 hrs) |
| `lessons.html` | Private and small group lessons, plus all 9 instructors |
| `elite.html` | Hit Factory Elite travel ball: tryouts, photos, sponsorship, donations |
| `parties.html` | Parties and events |
| `about.html` | Founders Nathan and Codi Fisher, and the mission |
| `contact.html` | Address, phone/text, email, Facebook, map |

All content comes from their current Jersey Watch site. Booking links go to their Swift page.
