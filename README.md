# The Hit Factory — website mockup

One-page site for **The Hit Factory**, an indoor baseball and softball training facility at 124 Plymouth St, Unit A, Lexington, Ohio 44904.

Plain HTML + CSS, no build step. Open `index.html` or deploy the folder to Netlify / GitHub Pages as-is.

## Before showing it off

- [ ] **Photos** — drop images into `images/` with these names (from the Facebook page or new shots):
  - `cages.jpg` — batting cages (the large photo in "Everything you need")
  - `elite.jpg` — Hit Factory Elite team photo
  - `gallery-1.jpg` … `gallery-4.jpg` — gallery strip (1 and 4 are wide slots)
  Empty slots show a light placeholder, so the page still looks finished without them.
- [ ] **Hours** — real hours from the owner (search `TODO` in `index.html`).
- [ ] **Parties / groups** — confirm this is offered, or delete that block.
- [ ] **Rates** — currently points to the Swift booking page; add a price list if the owner wants it on the site.
- [ ] **Logo** — swap the stitched-ball mark in the header for their real logo if they have one.
